# Railway Canvas Clone

日本全国の実地図で線路・駅・路線・ダイヤを作る、Railway Canvasの独立実装です。

## 起動

Node.js 22以上で実行します。追加パッケージのインストールは不要です。

```sh
node server.mjs
```

http://127.0.0.1:4173/ をブラウザで開きます。

## 検証

駅名は、画面上で40px以内に別の駅がある密集箇所では非表示にします。駅の点と線路は残し、ズームで駅同士が離れると名前を再表示します。残った長い駅名も重ならないようにし、選択中の駅名は優先します。

```sh
node --test tests/*.test.mjs
node --check dist/main.js
node --check dist/engine.js
node --check dist/map.js
node --check dist/persistence.js
node --check dist/existing-network.js
node --check dist/population-layer.js
node --check dist/elevation.js
node --check dist/editor-history.js
node --check dist/track-edit-state.js
node --check dist/game-clock-controls.js
```

自動テストとChromeでの操作結果、検証範囲は `docs/VERIFICATION.md` に記録しています。

## 基本操作

1. 「敷設 → 線路」で単線または複線の下書きを描きます。Escで今の描画区間を区切り、次のクリックから別の区間を描けます。
2. 「敷設 → 駅」の「新しく置く」で、駅構成・両数・配線を選んで複数の駅を仮配置します。「線路上に設置」では未確定の線路にも駅を置けます。「選択・移動」や駅の下書き一覧から、個別の位置・構成・配線を直せます。
3. パネル下端の「まとめて敷設」で線路と駅の建設計画を一括で確定します。仮配置だけでは課金せず、不正な駅や接続・資金不足があれば一部だけ建設しません。
4. 「路線」で建設した駅を起点・終点に選び、往路・復路の使用番線、両数・編成数・初電・終車を設定してダイヤを作ります。指定番線へ線路がつながらない場合や、進行方向に反する場合は作成できません。
5. 上部の「再開」「停止」、またはSpaceで時計と経営の進行を切り替えます。1×・10×・60×・300×を選べ、詳細の速度入力は0〜86,400秒に対応します。画面内で停止して再開すると直前の速度を使います。

道具メニューで敷設・路線・セーブ・設定を切り替えます。右上のパネルボタンで操作パネルを隠し、道具メニューを選ぶと再表示できます。建設費の合計と確定・破棄はパネル下端に固定します。駅構成と両数は同列に表示し、構内図・費用内訳・番線配線・路線の使用番線は必要なときに開きます。駅の詳細配線は「番線・接続・進行方向」、建設済み駅は「建設した駅」を開いて操作します。

Tは線路の新規描画、Sは駅配置、Vは線路の選択・編集、Lは路線設定です。入力欄やダイアログの操作中にはこれらのキー操作を適用しません。セーブ画面は現在の自動保存先を表示し、保存枠の「読込」で切り替えられます。

「線路上に設置」では下書きの線路・建設済みの自作線路・青い既存線路の途中に駅を追加できます。自作複線上は2線以上を選んでください。青い既存線路上でも1面1線から4面8線まで、8種類すべてのプリセットを使えます。

「既存線に合わせる番線」で、元の線路と重ねる番線を確定前に選べます。単線・青い既存線路では1番線ずつ、自作複線では隣り合う2番線を選びます。「自動（中央の番線）」は従来の配置を使います。選択は駅ドラフトと建設済み駅の保存にも引き継ぎます。

## 曲線の描き方

単線・複線は「接線モード」と「通過点モード」を切り替えられます。新しく描く線の初期値は接線モードです。

- 接線モード：始点・終点を通り、中間の点で接線と曲がり方を決めます。中間の制御点そのものは通らず、その内側を滑らかに結びます。
- 通過点モード：置いたすべての点を通ります。編集中の点にある四角いハンドルをドラッグし、点の両側で対称な接線を調整できます。

次のクリックを含めた曲線をカーソル位置に予告します。「予測線・接線ガイドを表示」では接線の延長・制御線・仮の終点と、全長・最小半径・接線の交角の補助表示を切り替えます。モードを変更しても計画点は残り、手動ハンドルは自動位置に戻ります。この変更も「元に戻す」で戻せます。描画中の区間だけでなく、Escで区切った下書きも選択し直して点とハンドルを調整できます。ドラフトの保存・復元と一括確定にも、曲線方式とハンドルを引き継ぎます。

接線モードは二次、通過点モードは三次ベジェ曲線を使った独立実装です。急すぎる曲線や不正な交差は建設できません。曲線方式がない旧セーブのドラフトは従来の接線連続円弧として扱い、建設済みの形状も保持します。

## 下書きの選択・編集と履歴

「新しく描く」ではクリックで計画点を追加し、点の再クリックでその点を取り消します。描画中でも点をドラッグすると位置を変えられます。「選択・編集」では地図上の下書き、または「下書きの区間」一覧から区間を選び、点と接線ハンドルをドラッグして修正できます。このモードでは点をクリックしただけでは削除しません。Escで編集を終えると元の区間順に保存し、次のクリックから別の区間を描けます。

選択した線路下書きは「この下書きを削除」またはDeleteで個別に破棄できます。駅の下書きは一覧の「削除」で個別に破棄します。費用はかかりません。下端の「計画を破棄」は、線路と駅の下書き全体を破棄します。

建設計画は、線路・駅どちらの画面でも「元に戻す」「やり直す」ボタンとCtrl+Z／Ctrl+Y／Ctrl+Shift+Zで80操作まで戻せます。点・ハンドルの1回のドラッグは1操作です。駅の追加・移動・設定変更・削除、線路下書きの編集、一括敷設・計画の破棄・敷設済み線路の削除を対象にします。敷設のUndo／Redoは計画全体の設備と下書きを戻し、該当工事の支払額と建設費の差額だけ調整します。ゲームの時計・速度、運行収入や乗客数の進行は巻き戻しません。やり直しに必要な資金が不足した場合は変更しません。

履歴はこの画面の操作中だけ保持し、再読み込み・新規ゲーム・セーブの読込で消去します。建設済み駅の配線や路線設定など、履歴外の変更があった場合は、次の建設計画の操作時に古い履歴を消去して変更を保護します。

「選択・編集」で敷設済みの自作線路を選ぶと、「選択した線路を削除」またはDeleteで撤去できます。確認画面には、その線路に依存する渡線・駅・路線も表示します。削除による払戻しはなく、この画面のUndoで設備と関連路線を復元できます。青い既存線路と駅専用の構内線路は直接削除できません。

## 駅の構成

| 構成 | ホームの種類 |
|---|---|
| 1面1線 | 片側ホーム |
| 1面2線 | 島式ホーム |
| 2面2線 | 相対式ホーム |
| 2面3線 | 片側＋島式 |
| 2面4線 | 島式ホーム |
| 3面4線 | 相対式＋島式 |
| 3面6線 | 島式ホーム |
| 4面8線 | 島式ホーム |

ホーム長は1～20両、1両20mです。角度入力と45°回転のほか、地図上の右ドラッグ（左右）またはShift＋ホイールでも5°ずつ回転できます。位置を変えるときは「選択・移動」で駅の下書きを選び、地図をクリックします。選択済みの駅ドラフトは中心を保って回転します。通常のホイールは地図のズームです。線路上への配置では線路の向きに合わせます。建設費は駅本体・ホーム面数と両数・追加構内線路をまとめて計上し、建設計画の確定時に支払います。

新しく先置きする駅は、初期状態では番線ごとに独立した配線です。各番線のA側・B側を「番線専用口」「共通口1～4」「車止め（終着）」から選び、進行方向を「双方向」「A→B」「B→A」で指定します。A側／B側は駅を基準にした呼び方で、方角は表示しません。専用口は各番線からまっすぐ延び、同じ側で同じ共通口を選んだ番線だけが合流します。車止めは片側だけ設定でき、折り返しできるよう進行方向を双方向にします。

複数の線路と駅の未確定計画を、ドラフトとして自動保存します。駅の「新しく置く」はクリックのたびに別の駅を追加し、「選択・移動」は個別の駅を編集します。Escapeは現在の線路の描画・編集区間を区切り、地図上に下書きを残します。次のクリックは前の区間から自動でつながず、新しい区間の始点になります。再開ボタンやモードの選び直しは不要です。区切った下書きの端点に近づけると端点を強調し、同じ座標へ吸着させて接続できます。右クリック取消は描画中・選択中の線路下書きの末尾から1点ずつ戻します。

下書きはすべて表示・保存し、再読み込み後も復元します。「まとめて敷設」は2点以上ある線路とすべての駅を一括で検証・建設し、失敗した場合は設備・資金・下書きを保持します。1点だけの線路下書きは未建設のまま残します。「計画を破棄」は線路・駅の全下書きを破棄します。旧版の単一区間ドラフトと1駅だけのドラフトも読み込めます。下書き線路を参照する駅はその線路へ接続し、参照先を消しても近くの別線路へ勝手に移しません。

駅一覧の「番線・配線」から、先置きした駅や青い線上に新設した駅の配線を建設後にも編集できます。接続口が移った場合は外部線路をつなぎ直してください。変更で既存路線が走行できなくなる場合は保存せず、元の配線・路線・資金を保持します。追加工事費がある場合は計上します。「両端ですべて合流」も選択でき、配線設定がない旧セーブは従来の合流構造として読み込みます。

構内線路は経路計算にも使います。自作線路上に置く駅は既存の1線または2線を再利用して追加側線を作ります。列車の占有予約や衝突回避はシミュレーションしていません。

## 路線の使用番線

路線作成時に、起終点と途中駅の使用番線を往路・復路で別々に選べます。「自動」は接続と進行方向に合う番線を選びます。指定した番線を通らない経路や、通行できない方向での設定は拒否します。作成済みの路線も一覧の「使用番線」から変更でき、経路とダイヤを再計算します。失敗時は元の路線を保持し、番線指定もセーブに保存します。

## 地図の表示

自作の単線は青緑の1本線、複線は緑の2本線で表示し、方向矢印も付けています。縮小しても区別できるよう、複線の間隔などを最小画素幅で誇張します。拡大すると枕木や駅のホーム・番線を表示します。NIMBY Railsを参考に本数と方向を読み取りやすくした独自描画で、同作の実装・仕様との一致を意図するものではありません。

背景はOSM・衛星航空写真・標高・白紙から選べます。「標高」は国土地理院の色別標高図です。提供タイルのズーム5～15を、地図のズーム4～22に合わせて拡大・縮小表示します。標高による建設費補正はありません。

左下のレイヤーメニューには、背景と独立した「人口ヒートマップ」があります。標高を含むどの背景にも重ねられ、背景と人口表示の状態を保存します。WorldPop 2020の約1kmメッシュの推計人口で、現在の実人口や実測の鉄道利用者数ではありません。縮小時には表示を集約します。

地図の「‰」ボタンで勾配測定を有効にし、始点A・終点Bの2点をクリックすると、標高差・水平距離・平均勾配を表示します。勾配は `(Bの標高 − Aの標高) ÷ 水平距離 × 1000` で、A→Bの上りが正、下りが負です。標高は選んだ2点だけ国土地理院の標高取得APIへ問い合わせ、成功値をキャッシュします。カーソル移動では問い合わせません。データがない地点や通信できない場合はエラーを表示し、「測り直す」で再選択できます。測るのは地表2点間の直線の平均で、線路の高さや途中の起伏を追った縦断勾配ではありません。

## 新規ゲームと全部リセット

右下の「新規ゲーム」、設定またはセーブ画面から開けます。確認画面では削除対象と保存枠数を表示します。

- 通常の新規ゲームは、現在の建設・路線・資金・時計・地図表示・資金無制限を初期化し、名前付きセーブを残します。選択中の保存枠がある場合は最後の状態を保存してから始めます。
- 「名前付きセーブもすべて削除する」を選ぶと、現在の進行と名前付きセーブをまとめてリセットします。消去するのはこのゲームの4つの保存キーだけで、他のサイトやアプリの保存領域には触れません。

初期所持金は1000億円、日時は2026年1月1日6時です。人口表示も初期状態のオフに戻ります。既設の青い鉄道網・人口・地価などの参照データは消さず、プレイヤーの建設と進行を初期化します。保存操作に失敗したときは元データの復元を試み、成功するまで画面内のゲームを置き換えません。別タブにもリセットを通知します。

## 既存線路との接続・その他の差分

「新しく描く」で現在の区間の点を再クリックすると、その点だけ取り消せます。「選択・編集」では点クリックは選択として扱います。右クリックは描画・選択中の下書きの末尾から1点ずつ取り消し、残った点から線と費用を再計算します。ほかの区間は保持します。

単線・複線の端点を既存の青い線路に吸着して接続できます。「路線」で青い駅をクリックすると、既設駅を起点・終点に選べます。「敷設 → 駅」で青い駅を先に利用登録しておくと、その駅を通る路線は中間停車もします。未登録の既設駅は通過します。

「線路上に設置」で青い既存線路の途中をクリックすると、選んだプリセットの新駅ドラフトを追加できます。カーソルを動かすと近くの接続先線路を示し、その線に合わせて駅の位置と向きを予告します。配置後は接続先を保持し、「選択・移動」で選んだ駅を置き直すと変更できます。

共有線路1本を再利用し、追加番線は駅専用の構内線路として建設します。初期状態では各番線の端がまっすぐ独立しており、元の共有線路と重なる番線だけが接続済みです。追加番線を使うときは、その接続口へ外部線路を描いてつなぎます。近くの青い線路へ自動で合流することはありません。路線の使用番線は、実際につながった番線から選びます。元の共有線路を使う番線は、元の接続と双方向通行を維持します。

本体・ホーム・追加線路の工事費と、その駅・構内線路の維持費を計上します。元の全国線路網を所有線路へ複製しません。接続する元データの区切りはまたいで配置でき、実際の線路端で必要な長さが足りない場合は拒否します。青い既設駅そのものを選ぶ場合は、従来どおり無料の利用登録を確定します。以前の合流配線の駅は保存した接続を維持し、駅一覧の「番線・配線」から明示的に変更できます。

既存の青い網は共有の双方向線路、既設駅は20両対応として扱います。既存設備の建設費・維持費は無料、列車の運行費は通常どおりです。線路が交差するだけでは接続しません。紫の新幹線・実在事業者との契約・軌間や電化方式の違いはモデル化していません。

登録した既設駅に限り、駅座標から80m以内の複数線路を共有駅として接続する簡略モデルです。未登録駅や一般の交差点ではこの接続を作りません。

配信後の `features.html` に元サイトとの機能比較、`credits.html` にデータ出典とライセンスを掲載しています。詳細な調査と検証記録は `docs/` にあります。

全国の鉄道・駅、地価、人口、町名は出典を明記した公開データです。元アプリの実装コードは含みません。需要・運賃・車両の力学・用地面積は独自近似で、元サービスのアカウントやセーブデータとは連携しません。名前付きセーブはブラウザ保存、共有は圧縮したURLの独立コピーです。

`dist` のファイルは静的ホスティングにそのまま配置できます。`.json.gz` は圧縮データとしてアプリが解凍するため、Content-Encodingで自動解凍しない設定で配信してください。
