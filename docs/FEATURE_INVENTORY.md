## 全体

これは路線図を描く図形エディターではなく、日本全国の実地図を使った架空鉄道建設・経営ゲーム。左約 75% に地図、右約 25% に操作パネル。地図上部だけに所持金・ゲーム内日時・進行速度がある。

- 初期所持金: 100,000,000,000 円（1000 億円）。
- 初期日時: 2026/01/01 06:00:00 日本時間。
- 初期速度: 0（停止）。「現実1秒 = [数値] 秒」の入力で 0～86400 の整数を設定。
- 操作パネル: 「敷設」「路線」「セーブ」「設定」の 4 タブ。
- タブを切り替えると一時的な案内メッセージを消す。
- 画面幅に応じて文字サイズや入力配置が変わる。タッチ操作あり。

## 地図

確認した機能:

- 初期中心: 東京駅付近（緯度35.6812、経度139.7671）、ズーム10.6。
- ドラッグで移動。ホイールでカーソル位置を基準に滑らかに拡大縮小。
- ダブルクリックで +1、キーボード `+` / `=` で +0.7、`-` で -0.7。
- タッチの 2 本指ピンチで拡大縮小。
- ズーム範囲4～22。日本周辺の緯度20～48・経度120～155を有効な保存ビューとして扱う。
- 左下「地図の種類」のレイヤーメニュー: OpenStreetMap / 衛星・航空写真 / 白紙。
- レイヤーメニューはマウスホバー・フォーカス・ボタンで開き、外へ出る・Escape等で閉じる。
- レイヤー選択、地図中心、ズームをブラウザに保存し再読込時に復元。
- OSM: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`（ソースは z19 まで、それ以上は拡大）。
- 航空写真: 国土地理院タイル。z14以上 `seamlessphoto` jpg、z9以上 `lndst` png、小縮尺 `modis` png。ソース z18 まで。
- 全国の在来線・新幹線・既設駅を描画。青系の既設線と駅、緑系のプレイヤー線路。
- 大きく拡大すると既設駅名を表示。駅クリック時は駅名ポップオーバーと選択ハイライト。
- 既設駅は地図の参照情報。プレイヤー路線の起終点には架空鉄道の駅を選ぶ必要がある。
- 表示中のタイルだけ取得。通信エラー時の地図再読込ボタンあり。
- 地図・鉄道・住所の出典表示。

公開メタデータの収録数: 在来線既設駅8972、リンク9603、新幹線駅109、新幹線形状245本、既存列車92444、停車時刻1513706。地理形状は国土交通省 N02-25 / CC BY 4.0、町名は Geolonia japanese-addresses / CC BY 4.0。

## 敷設: 線路

- 「線路」「駅」のサブモード。
- 線路種別は単線・複線・渡線・両渡線。初期は複線。
- 単線と複線: 地図を複数回クリックして制御点を追加。最初は直線、以降は接線を連続させた円弧。ホバーで次区間の予告線を表示。
- 計画線の線路工事費・土地取得費・合計を表示。
- 「敷設」で計画全体を確定・課金。「取消」で計画全体を取消。種別変更時も未確定計画を取消。
- 既設のプレイヤー線路近くで吸着し、始終点を物理接続して分岐・延伸できる。吸着は画面上最大10pxかつ地上80mまで。
- 接続点で計画を終えたらその先に追加点を置けず、「敷設」「取消」を選択する。
- 同一点、始点に2m以内の点、自己交差、無接続交差、既設プレイヤー線路との重複などを拒否。
- 曲線は内側線路の制限速度が15km/hを下回る急曲線を拒否。
- 所持金不足時は敷設不可。失敗理由を警告表示。
- 単線は独立した双方向の物理線路、複線は左右別々の一方向物理線路。左右中心間隔1.5mを計算に使う。
- 渡線: 既設プレイヤー線路の別々の物理線路へ吸着させた2点のみ。接線を連続させるS字曲線で接続。途中点追加不可。
- 両渡線: 同じ既設複線上の2区間を指定。2本の対角渡線を一括敷設。別複線同士には置けない。
- 建設後の線路そのものを一覧削除する UI はない。undo/redo UI もない。

費用:

| 項目 | 計算 |
|---|---|
| 複線工事 | 50億円/km |
| 単線・渡線工事 | 25億円/km |
| 複線用地幅 | 9m |
| 単線・渡線用地幅 | 5m |
| 土地代 | 土地面積×地価。2026年の地価データを近傍補間し、過去に取得済みの用地との重複面積を控除 |

## 敷設: 駅

- ホーム対応両数は1～20両。1両20mとして長さ20～400m。
- 建設したプレイヤー線路上にカーソルを置くと、予定ホームの輪郭と費用を表示。クリックですぐ設置・課金。
- 渡線上は駅を置けない。
- 線路端からホームがはみ出す場所、同じ線路上の他駅ホームと重なる場所は拒否（2m余白）。
- 駅本体1億円+ホーム1両あたり8000万円。1両駅は1億8000万円。
- 駅名は仮に「新駅N」を付け、非同期で場所の町名を調べて自動命名。ユーザーが先に名前を編集すれば自動変更しない。
- 駅一覧のテキスト入力で直接改名。48文字まで。入力中も地図名に反映、change/Enterで保存。空欄は元の名前に戻す。
- 一覧にホーム対応両数を表示。駅行クリック・キーボードEnter/Spaceで駅を中心に最低ズーム14まで拡大。
- 駅の削除は確認ダイアログ。削除駅を起終点にする路線も削除する。費用払戻しはない。
- 拡大率によって駅を青い点または実寸のホーム形状として描く。

## 路線・ダイヤ

- 路線タブで地図上の自作駅を2つ選んで起点・終点とする。3つ目の選択で選び直し。
- 同じ駅を2回選択できない。起終点の線路に走行可能な物理接続が必要。
- 路線名48文字、車両1～20両、投入編成数1～99、初電（初期06:00）、終車（初期24:00）。
- 初電・終車はHH:MM形式、最大29:59。終車が初電より前なら翌日扱い。
- 「路線・ダイヤを作成」で往復経路・中間停車駅・所要時間・等間隔ダイヤを計算して路線を追加。
- 往路も復路も物理的に走行可能な線路を要求。復路不足なら複線のもう1本・渡線を確認する警告。
- 全停車駅のホーム長が車両両数以上である必要がある。駅間距離5m未満は拒否。
- 最高速度130km/h、曲線速度は最大130km/hかつ概算 `sqrt(11.8×半径m)`。
- 牽引力・走行抵抗・速度依存加速・減速の計算を使い駅間所要時間を積算。
- 中間駅停車30秒、終点折返し300秒。往復所要時間=2×(片道所要+300秒)、運転間隔=往復所要/投入編成数。
- 路線一覧に「片道n分 / n分間隔 / n両×n編成」を表示。
- 路線行クリックで選択し、路線全体が地図に収まる位置・拡大率へ移動。
- 路線削除は確認ダイアログ。路線作成後の編集 UI はない。
- ダイヤの運行は収支に反映される。地図上を走る列車アニメーション描画は公開実装に見つからない。

## 経済・需要

上部に表示されるのは所持金・日時・速度のみ。詳細な経営記録は内部データとセーブに保持し、独立した経営ダッシュボードはない。

- ゲーム内の経過時間に応じ線路・駅維持費、車両維持費、乗務員費を引く。
- ダイヤの発車イベントごとに運賃収入と運行費を反映。
- 線路維持費2000万円/km/年。単線相当は複線の半分。
- 駅維持費300万円+30万円×ホーム両数/年。
- 運行費50円/両km。車両維持費8000円/両/日。
- 乗務員費(運転士3505+車掌2910)×1.3円/編成時間。出庫前後に各15分準備時間を含む。
- 車両購入費はない。
- 所持金が負なら赤色表示。
- 需要は2駅以上または路線作成時にWeb Workerを遅延起動する。
- 全国 WorldPop 2020 1km 推計人口、66063固定ゾーン、2086450固定ODリンクを使用。実測ODではなく地理・人口による重力モデル。就業も推計代理値。
- 徒歩・自転車・車・実在鉄道・プレイヤー鉄道を、所要時間・運賃・乗換・混雑・嗜好に基づき確率選択。
- 節約志向46%、時間志向34%、快適志向20%。プレイヤー車両容量は140人/両。
- 実在鉄道は既存時刻表から直通・1回乗換等を比較。新幹線時刻表は未収録。
- 運賃は各事業者にJR東日本幹線モデルを近似適用、事業者が変わると初乗りを再計算。
- 朝・昼・夕・夜の方向別需要・運賃収入を算出。未較正のゲーム内モデルであると公開メタデータに明記。

## セーブ・共有

- 建設内容・所持金・日時・収支は localStorage に自動保存。地図ビューとレイヤーも保存。
- 再読込時に復元。手動保存ボタンは不要。
- 「アカウントセーブ」はらこなすGamesへのログインが必要。ブラウザのChromeプロフィールのログインとゲームアカウントログインは別。
- 名前1～60文字で新規セーブを作成。その後は選択中の枠だけを自動更新。新しい枠作成時に以前の枠は分岐点の状態で残す。
- 一覧に更新日時・現在プレイ中/自動保存対象を表示。ページングの「さらに表示」。
- 行クリック・Enter/Spaceで読み込みの確認ダイアログ。現在のプレイ内容を完全に置換する。
- 名前変更、削除（確認ダイアログ）、共有のボタン。
- クラウド削除は枠だけを消し、現在のブラウザのプレイは残す。既に発行した共有コピーも残る。
- 共有リンクはその時点のセーブの独立したコピー。ライブ同期ではない。
- リンクをコピーでき、受信側は確認してブラウザのプレイを置換。元のセーブへは影響しない。
- 共有コピーはアカウント枠から切り離した状態で開く。保存したい受信者は別名で新規保存。
- ローカル初期化「セーブデータ消去」は確認ダイアログ。線路・駅・路線・資金・日時・経営記録・無制限ロック・地図ビューを初期化。アカウントの名前付きセーブは残す。
- ログイン・クラウド枠の操作成功は本調査では未実測。公開親ページとのpostMessage通信に依存する。

## 設定

- 設定項目は「資金無制限」のみ。
- 確認ダイアログで有効化すると所持金を `¥ ♾️` 表示し、資金を減らさず建設・運行できる。収支記録は引き続き積算。
- 一度有効にするとそのブラウザのプレイで解除不可。通常セーブ読込でもロック継続。
- ローカルの「セーブデータ消去」で最初からやり直すと解除。
- 保存失敗時はエラーを表示。

## 元ゲームに見つからない機能

以下は公開UIとイベント実装に見つからなかった。クローン側に追加する場合は追加機能と区別する。

- undo/redo、計画の1点だけを戻す操作。
- 確定した線路の削除・移動・制御点編集。
- 自作路線の色指定・線幅・駅マークデザインなどの図形編集。
- 列車アニメーション・車両外観エディター・運転画面。
- 路線作成後の設定編集、時刻表一覧表示。
- 地点検索・住所入力・地名ジャンプ。
- JSON・PNG・SVGのファイル書き出し・読み込み。
- 独立した経営グラフ・需要ヒートマップ等。

## クローンでの再現境界

- 元らこなすGamesアカウントの認証・クラウドデータをクローンの別originから直接利用する仕組みは確認できない。クローン側では独立した保存機構・共有データとして再現する必要がある。
- 全国需要・実在時刻表の完全な再現には大量データと計算モデルが必要。軽量な独自近似を使う場合は「近似」を明示する。
- 地理背景の公的データ・OSM・国土地理院などは出典とライセンスを付けて利用する。
