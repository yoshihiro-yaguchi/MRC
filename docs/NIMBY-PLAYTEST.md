# NIMBY Railsの操作確認とクローンへの設計メモ

確認日：2026-11-13。起動中のNIMBY RailsをWindowsの実画面で操作した記録。クローンの実装変更は行っていない。クローン側はこの時点で162テスト成功。

## 実画面で確認した操作

開始時には未確定の建設計画がなかった。確認中に作ったものはすべて未確定の計画で、「Build All」は押していない。

| 操作 | 確認できた結果 |
|---|---|
| 2点をクリックして線路を描く | 2,854mの計画を作成した。 |
| Escを押す | 作成から選択へ切り替わり、描いた計画は残った。 |
| 端点を選択してドラッグする | 端点が動き、計画長が3,959mへ変わった。 |
| 端点の進入側接線ハンドルをドラッグする | 接線と曲線の形が変わり、4,027mとなった。 |
| 両端の高さ設定を「+1」にする | 線路が青い高架表示になり、道路干渉の表示がなくなった。高さの単位・工事費への影響は確認していない。 |
| `N`で延伸を開き、既存の計画端点から次の点を置く | それまでの曲線も滑らかに再計算され、連続した8,520mの計画になった。 |
| 計画線の途中をクリックし、別の点へ線を描く | 分岐を追加し、全体で11,734mとなった。 |
| 駅ツールをアイコンから開き、2点で配置する | 「安楽亭」という駅を配置し、全体で12,706mとなった。駅の向きとホームを手作業で決める操作だった。ツールチップには`Y`が表示されたが、キー操作では開いていない。 |
| 駅ツールでEscを押す | 駅の作成モードを終了し、12,706mの線路と駅の未確定計画は残った。 |

右側の人口・建物表示を一時的に切り替えて、線形を見やすくして確認した。確認後は元の`DefaultPopBuildup`のチェックがオンであることを画面で確認した。作成した線路と駅の計画は、見直せるよう未建設のまま残した。列車の設定・実走行・運賃収支は試していない。

`Ctrl+Z`も試したが、自動操作では取り消しが起きたことを画面で確認できなかった。ヘルプの記載だけを根拠に、Undoが動作したとは扱わない。

画面記録：駅まで配置した [nimby-station-playtest.jpg](</C:/workspace/railways canvas clone/reports/nimby-station-playtest.jpg>)、分岐を作った段階の [nimby-playtest.jpg](</C:/workspace/railways canvas clone/reports/nimby-playtest.jpg>)。NIMBY側の記録は人口・建物表示を一時的に切り替えた状態。比較対象のクローン画面は [curve-controls.jpg](</C:/workspace/railways canvas clone/reports/curve-controls.jpg>)。

## クローンで重視する点

既存の全国鉄道網を利用できることと、番線・配線を設定できるプリセット駅は維持する。NIMBY Railsのすべての画面や建設方式を置き換えるのではなく、線形を作って修正する操作を参考にする。

以下は未実装の改善候補であり、上の操作確認とは分けて扱う。

| 優先度 | 改善候補 | 現在のクローンとの関係 |
|---|---|---|
| 高 | 計画点をドラッグして位置変更 | 現在は再クリックで取消、ハンドル以外のドラッグは地図移動。ユーザー指定の再クリック取消を残し、ドラッグだけ移動に割り当てると両立できる。 |
| 高 | Escで区切ったドラフトを選んで再編集 | 現在のハンドル編集は描画中の区間だけ。過去の区間も選択して点・接線を直せれば、全取消からの作り直しを減らせる。 |
| 高 | 編集操作のUndo／Redo | 点取消・ハンドル変更・モード切替・全取消を戻す履歴がない。まず未確定の編集操作を対象にする。NIMBY側のUndo動作は今回未確認。 |
| 中 | 接線・角度・ガイド交点への拘束 | 現在はガイドを描画するだけで、吸着対象は駅の接続口・下書き端点・既存線路。修飾キーで接線延長や角度へ拘束できると、接続を合わせやすい。 |
| 中 | 選択・描画・延伸の文脈とショートカットの案内 | 実際に使った`N`、駅ツールに表示された`Y`、選択後の端点・途中点からの延伸が参考になる。クローンのEsc直後に別区間を描ける動作も維持する。 |
| 中 | モードごとの手動ハンドル保持 | 現在は曲線モードを切り替えると手動ハンドルを初期化する。接線／通過点を比較して戻せるよう、モード別保持またはUndoを検討する。 |

クローンの接線・通過点モードは二次／三次ベジェ曲線による独立実装。今回の操作確認から、NIMBY Railsの内部の曲線計算式や接続判定まで同一だとは判断しない。
